# 主对话 / 副对话

任意会话都能开副对话：主对话留在左侧，副对话在右侧栏以原生会话标签打开；主对话维护一份可版本化的总要求，副对话完成后提交变更提案。

## 流程

1. 任意会话，输入框工具栏点 `+ 副对话`；首次点击会初始化当前会话的总要求。
2. 右侧栏打开一个 `副对话 xxxx` 标签，里面是完整原生会话；可以继续开多个标签。
3. 副对话完成后点 `完成并提交`（标签头或输入框工具栏）。
4. 主对话点 `面板`：提案逐段 diff 采纳 / 拒绝，总要求全文编辑，版本历史与回滚。
5. 副对话的 `同步` 更新快照，`回主对话` 切回主对话。

## 存储

```
<工作区>/.dsh/master-prompts/<主对话会话ID>/
  prompt.md, meta.json, versions/, proposals/
```

## 规则

- 没有专属 Agent 模式；任意模式、任意工作区可用。
- 侧边栏不加任何插件标记。
- 副对话只有一层；副对话只提交提案，不能直接写总要求。
- 主对话不读副对话完整记录，只接收提案摘要。
- 外部编辑 `prompt.md` 会记为 `external` 版本；回滚生成新版本。

## 限制

- 总要求不宜过长。
- 提案按当前版本重算差异，并行取舍由用户逐段决定。
- 快照需要手动同步。
